# bin123apple.github.io

Personal homepage for Bin Lei — Ph.D. student at the University of Minnesota.

Plain HTML/CSS, no build step. Deployed via GitHub Pages with `.nojekyll`.

## Local preview

```bash
python3 -m http.server 8080
# open http://localhost:8080
```

## Files

- `index.html` — single page
- `styles.css` — styling (light/dark via `prefers-color-scheme`)
- `assets/profile.jpg` — profile photo
